# Weather Station Dashboard

A personal dashboard to monitor weather stations with detailed reports, forecasts, and trends.

## Description

- View detailed weather reports per station (temperature, wind speed, wind direction, pressure).
- Add, edit, or delete weather reports easily.
- See the latest weather summary for each station with icons.
- View live temperature forecasts and station locations on a map.

## Getting Started

### Installation

1. Navigate into the project folder:

   ```bash
   cd weather_app
   ```

2. Install dependencies:

```bash
 npm install
```

3. Run the project:

```bash
 npm start
```

4. Now navigate to [http://localhost:4080](http://localhost:4080) to see the site.

## Technologies

- JavaScript — For adding interactivity and dynamic behavior.
- Day.js — A lightweight library for date manipulation and formatting.

- OpenWeatherMap Weather Conditions API — Provides weather data and forecasts.
- Node.js — A JavaScript runtime for building server-side applications.
- npm — The Node.js package manager for installing and managing.
